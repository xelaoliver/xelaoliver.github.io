Trigonometry

All you need is a basic highschool level understanding of trigonometry (SOH CAH TOA) to program fun things with circles, polar coordinates and directional movements. 
// returns an [x, y] coordinate from a point described by an angle and radius

function pointOnCircle(radius, radian) {
    return [Math.cos(radian)*radius, -Math.sin(radian)*radius];
}
This function is a useful polar to cartesian algorithm, where you can specify a radius of a circle and a radian (distance from the center of a circle and direction in layman's terms).
