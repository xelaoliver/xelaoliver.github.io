Trigonometry

All you need is a basic highschool level understanding of trigonometry (SOH CAH TOA) to program fun things with circles, polar coordinates and directional movements. 
// returns an [x, y] coordinate from a point described by an angle and radius

function pointOnCircle(radius, radian) {
    return [Math.cos(radian)*radius, -Math.sin(radian)*radius];
}
This function is a useful polar to cartesian algorithm, where you can specify a radius of a circle and a radian (distance from the center of a circle and direction in layman's terms). Braille pixels

Have you got a buffer of pixels that you don't want to display orginarily using a graphics library or in the terminal using plain-old boring characters? After a bit of thinking and poking around with the Unicode braille patterns, I have a solution for you! 
// returns the braille character for a pixel array
function braille(bits) {
    const dotValues = [1, 8, 2, 16, 4, 32]
    let value;
    for (let i = 0; i < 6; i ++) {
        value += bits[i]*dotValues[i];
    }

    return String.fromCodePoint(0x2800+value);
}
This function takes a 1 dimensional array used to represent the braille character matrix, example:

Braille character: ⠗
  Representation*: 1 0
                   1 1
                   1 0
      Array input: [1, 0, 1, 1, 1, 0]

*where 1 corresponds to dot, 0 no dot

Projection equation

Probably one of my favourite equations when I was first learning programming. Take an X, Y, Z coordinate and convert it into 2 dimensional screenspace to be displayed on the screen. It's very simple, but the capabilities of it are limitless. I found Tsoding does an excellent demonstration of the formula in his video about the One Formula That Demystifies 3D Graphics on YouTube. The formula: 
x' = (x+1)/z*width
y' = (1-(y+1)/z)*height
