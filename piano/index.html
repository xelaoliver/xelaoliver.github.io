MIDI

I'm no musician (but I do like some good ol' piano), but MIDI is a digital recording format that stores musical instructions (note, duration, pitch... all of that jargon). It's almost... a piano roll.


Source: Wikipedia

You see, the humble piano roll stores information about each key: when to play a note and for how long. As an analogy (too keep this short), MIDI is just like this.

One could very easily programmatically itterate through a MIDI file, read all information about notes and then append them to an array for playback later. I'm barely scratching the surface of MIDI, but this is all I used for this project.

The HTML Canvas API

Probably my favourite HTML element of all is the Canvas API. It's an incredibly versatile and powerful tool for incorporating 2D graphics into a webpage. Almost all of my HTML/JS projects utilise it in some way, shape, or form - and for good reason. With the Canvas API, you can effortlessly draw lines, polygons (and even build 3D graphics from them), images, text, and so much more. The possibilities are practically endless.
